# Rural Health Education Platform  
A community-focused health education project created for rural Alabama residents, seniors, and individuals managing chronic conditions.  
This platform provides **clear, simple, mobile‑friendly health information** designed for real‑world use in clinics, churches, senior centers, and community spaces.

---

## 📌 Project Purpose
Many rural communities face barriers to:
- Reliable health information  
- Transportation and healthcare access  
- Digital literacy  
- Chronic disease management  

This platform helps bridge that gap by offering:
- Easy‑to‑read health guides  
- Mobile‑optimized pages  
- QR‑code–based distribution  
- Topics aligned with CDC/NIH recommendations
